# Tarea 3 - Alonso Genery

Se agregó la lógica de comentarios en la parte de la visualización de aves. El usuario ingresa su nombre y luego puede comentar en cualquier ave lo que quiera de momento (no tiene palabras restringidas). Este comentario se agrega a las tablas SQL de comentarios, para guardar todos y que luego se vean en la parte de información para el resto de usuarios.

## Estadisticas

Se agregaron los 3 gráficos solicitados, uno de línea, otro de torta y el último de barras, para mostrar los datos de usuarios registrados, las aves y las fechas de registro, junto con un botón al final de la página que lleva de vuelta a la portada.
